# Levels

A goals and habits tracker with an RPG layer: habits earn EXP, streaks
multiply it, and levels unlock new areas of life. Built in public as an
ongoing Angular project.

## Tech
Angular (latest) · TypeScript · RxJS · Signals · Jasmine/Karma · WCAG/AODA-conscious UI

## Current status
In progress. First slice: add, list, and check off daily habits (local state only).

## Roadmap
- Good/bad habit types
- EXP and streaks
- Later: levels, accountability features, mobile build via Capacitor

## Why this exists
I'm updating my Angular work to the current framework and documenting
what changed and what I learn along the way.
